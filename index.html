Find and replace across the document
How this works. Every page is scanned for text runs containing your search term. Each match becomes a cover-and-redraw edit that you can still adjust or remove individually afterwards. A run is the unit a PDF stores — usually a line or a fragment of one — so a phrase split across two runs will not be found.
How the text editing works

A PDF does not store text the way a word processor does. It stores glyph codes placed by explicit position matrices, drawn using fonts that are normally subsetted — only the glyphs the document already uses are embedded in the file. Genuine in-place editing would mean rewriting the page content stream and re-encoding characters against a font that may simply not contain the letters you want to type. No browser library does this.

So this editor covers and redraws instead. When you pick a line, its exact baseline, width and font size are read from the page. The colour immediately around it is sampled off the rendered pixels, a rectangle in that colour is painted over the original, and your replacement is drawn at the same baseline using whichever of the standard fonts best matches the original's weight and slant.

Works beautifully for: names, dates, numbers, marks, headers, titles, single-line labels, typo fixes, and rolling a worksheet forward a year.
Expect trouble with: text sitting on photographs or gradients, where a flat cover rectangle will show; justified multi-line paragraphs, which would need real reflowing; unusual embedded fonts whose letter widths differ noticeably from the standard set; and scanned documents, which hold no text objects at all — only pixels. On a scan the page will simply report no editable runs.

Every edit stays live and reversible until you export. Nothing is baked into the file until you press Download, so you can adjust the cover colour, nudge the baseline, or delete an edit entirely at any point.

Transforming the whole page:  

Erase / Paint: drag across the page — click then Shift-click joins the two points with a straight stroke, and Shift-drag locks it to horizontal or vertical. Fill: click inside a shape to flood it. Clone: click to set a source, then drag to stamp that area elsewhere — the cleanest way to cover a mark with the paper beside it. Once the source is set, the ring under your pointer shows the exact patch that will be stamped, so you can line it up before you press. History: brush the page as you opened it back in. Select / Lasso / Wand: mark out an area, then fill it, move it, delete it or smart-fill it (Esc deselects). Move: drag inside a selection to cut it out and drop it anywhere, Alt to copy. Resize / Rotate / Skew: with something selected they act on that object; with nothing selected they act on the whole page, which is how a crooked scan gets straightened — Straighten… traces an edge and levels it for you. Enter applies the transform, Esc cancels it.
Text: pick a face and a size, click where the words should start, and type. The box has no fill, so you can see the page underneath it while you place it, and it drags from anywhere — no button to press first — with a guide across the page and the exact position shown while it moves. Shift while dragging keeps it on one line. Enter finishes the label; Shift+Enter starts a second line.
Paste a picture: Ctrl+V (⌘V), or the button, drops whatever picture is on the clipboard onto the page with the resize handles already on it.
Scroll over the page to zoom (down to single pixels); hold Space or the middle mouse button and drag to pan; scroll over a slider to change it. Erase, Paint, Clone, History and Line draw a ring at the exact size of the mark they will make, at whatever zoom you are on — and with Clone that ring is filled with the pixels it is about to stamp, moving with the pointer.
Regenerate: type what you want in the purple bar and the AI redraws it. Select an area first and only that area can change; with nothing selected the whole page image is redrawn. It is one step either way, so Undo puts the page straight back. This is the only feature in PDF Studio that sends anything off this device: pressing it sends a picture of this page (never the PDF file) to Google's Gemini model, using an API key you paste in once and that is kept in this browser alone.
